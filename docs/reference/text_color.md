# Text color of the light or dark mode

Text color of the light or dark mode

## Usage

``` r
text_color(mode)
```

## Arguments

- mode:

  `"light"` or `"dark"`, the mode of the app.

## Value

A CSS color, the body text color of Bootstrap in that mode.

## Examples

``` r
crypto:::text_color("dark")
#> [1] "#dee2e6"
```
